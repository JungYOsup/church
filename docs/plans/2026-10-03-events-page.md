## Context

- spec:

  - 어디서: `src/app/events/page.tsx`

## 결정
- **질문과 답:**
  - 지난 행사: 보여 주지 않고 다가오는 행사만 보여 줍니다.
  - 태그: 하나만 고릅니다. "전체"와 태그 칩 중 하나이고, 고른 칩을 다시 누르면 전체로 돌아갑니다.
- **정한 것:**
  - **필터 상태는 URL(`/events?tag=연합`)에 두고, 서버 페이지가 `searchParams`로 거릅니다.** 칩은 `Link`입니다.
    - 주소를 공유하거나 뒤로 가기를 해도 같은 결과가 나오고, JS 없이도 동작합니다.
    - 클라이언트 컴포넌트가 필요 없습니다.
    - 요청마다 렌더링되므로 "지금"이 빌드 시각이 아니라 요청 시각이 됩니다. 다가오는 행사를 고르기에 더 맞습니다.
    - `useSearchParams`를 쓰면 목록이 Suspense 아래에서 클라이언트에서 그려지므로 쓰지 않습니다.
  - **순수 로직은 `src/lib/tags.ts`**(짝 테스트 `tags.test.ts`)에 둡니다. 교회 카드에도 태그가 있어 나중에 지도 페이지 필터도 같이 쓸 수 있습니다.
    - `parseTagParam(value)`: `searchParams.tag`(`string | string[] | undefined`)에서 첫 값을 꺼냅니다. 빈 값은 `null`입니다.
    - `collectTags(items)`: 중복 없는 태그 목록입니다. 많이 쓰인 순서로 놓고, 횟수가 같으면 가나다순(`localeCompare("ko")`)입니다. 자주 쓰는 태그가 앞에 오게 하기 위함입니다.
    - `filterByTag(items, tag)`: `tag`가 `null`이면 전부, 아니면 태그가 정확히 같은 항목만 원래 순서대로 돌려줍니다.
  - **데이터 계층:**
    - `getUpcomingEvents({ limit?, tag? } = {})`: `limit`가 없으면 전부입니다.
    - `getUpcomingEventTags()`: 다가오는 행사에서 모은 태그입니다.
    - Supabase 단계에서는 두 함수 안쪽만 쿼리로 바꿉니다. 홈은 `getUpcomingEvents({ limit: 6 })`으로 고칩니다.
  - **칩 목록은 다가오는 행사의 태그로만 만듭니다.** 그래서 칩을 눌러 빈 결과가 나오는 일은 없습니다.
  - **화면 구성(위에서부터):**
    - 페이지 머리: `CalendarDays` 아이콘, `h1` "행사", 설명 "지역 교회의 다양한 행사에 참여해보세요."
    - 태그 칩: `nav aria-label="태그 필터"` 안 `ul role="list"`. 줄바꿈 배치(`flex-wrap`)로 칩이 모두 보이게 합니다.
    - 목록: `section` 안에 `h2` "다가오는 행사"와 개수("총 8개" / "연합 태그 3개"), `EventCard` 격자
  - **칩 모양:**
    - 높이 32px의 둥근 알약 모양입니다.
    - 선택 안 됨: 흰 배경, 테두리, 진한 글자. 선택됨: `bg-primary`와 흰 글자, `aria-current="true"`
    - 포커스: `outline-hidden`과 `focus-visible:ring-3`
    - `scroll={false}`로 칩을 눌러도 화면이 위로 튀지 않게 합니다.
  - **격자:** 모바일 1열, 640px부터 2열, 1024px부터 3열, 1280px부터 4열입니다. 상위 계획서의 "태블릿 2열"을 따릅니다. `imageSizes`는 `"(min-width: 1280px) 25vw, (min-width: 1024px) 33vw, (min-width: 640px) 50vw, 100vw"`입니다.
  - **탭 제목:** 태그가 있으면 "연합 태그 행사 | 함께하는 교회", 없으면 지금처럼 "행사 | 함께하는 교회"입니다(`generateMetadata`). 필터를 바꿀 때 Next가 새 제목을 읽어 줍니다. `e2e/navigation.spec.ts`의 탭 제목 테스트는 `/events`만 보므로 영향이 없습니다. **(T4에서 바꿈: 탭 제목은 항상 "행사"이고, 바뀐 결과는 개수 문구의 `role="status"`로 알립니다. 변경 이력 참고)**
  - **빈 결과:**
    - 칩에 없는 태그(지난 행사의 태그, 잘못된 주소): "'기도' 태그가 붙은 다가오는 행사가 없습니다."와 "전체 행사 보기" 링크를 보여 줍니다. 몰래 전체를 보여 주지 않습니다. **(리뷰 반영으로 바꿈: 칩에 없는 태그는 글자를 다시 적지 않고 "고른 태그가 붙은 다가오는 행사가 없습니다."와 "맞는 행사 0개"를 보여 줍니다. 변경 이력 참고)**
    - 다가오는 행사가 아예 없을 때: 홈과 같은 "예정된 행사가 없습니다."
  - 메뉴 이름과 기본 탭 제목 "행사"는 그대로 둡니다.
